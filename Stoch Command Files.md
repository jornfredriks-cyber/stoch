Ticker source: newest file in `INPUT/` if present (any name/format), else the Darvas Raw Screener CSV.                                                                                                     | `OUTPUT/StochSignal_Backtest_Trades_<date>.csv`               |

Buy-only.                                                                                                            | `OUTPUT/StochSignal_Candidates_<date>.csv`                    |

Sweeps SL 4-10% × TP 1.5-3.5R × filter on/off (70 combos), ranked by total $ P&L, with a per-ticker win/loss breakdown + trade-level CSVs for the top 3. | `OUTPUT/StochSignal_SLTP_Sweep_<date>.md`                     |
| `RUN Stoch Fresh Scan.command`        | `screener.py` → `stoch_fresh_scan.py` | One-operation live buy-candidate scan: pre-filters Stoch's own NASDAQ+NYSE universe (same screener as the Sweet Spot scan), then flags tickers whose weekly %K crossed strictly above `entry_level` (default 32) within the last `lookback_weeks` (default 2) **fully completed** weekly bars — the current, still-forming week is always excluded — with %K>%D on that bar. No EMA50 "not stretched" gate (unlike `RUN Stoch Signal Scan.command`). Buy-only. | `Stoch Raw Screener_<date>.csv`, `OUTPUT/StochFresh_Candidates_<date>.csv` |

## Which one do I actually want to run?

- **Looking for new swing-trade candidates today** → `RUN Stoch Signal Scan.command`
- **Looking for candidates whose fresh buy crossover fired in the last 1-2 weeks, using Stoch's own screener universe in one operation** → `RUN Stoch Fresh Scan.command`
- **Want to know how the current Stochastic settings would have performed historically** → `RUN Stoch Signal Backtest.command`
- **Tuning the Stochastic length/smoothing itself** → `RUN Stoch Signal Sweep.command`
- **Tuning stop-loss/take-profit or testing a trend filter** → `RUN Stoch Signal SLTP Sweep.command`
- **Working with the older Sweet Spot strategy instead of the Signal one** → `RUN Stoch Sweet Scan.command` (live) or `RUN Stoch Backtest.command` (historical)
